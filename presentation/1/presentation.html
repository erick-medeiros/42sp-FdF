01 · Introdução

Visão Geral

FdF é um projeto de visualização gráfica que converte mapas de altura 2D em uma representação 3D wireframe.

  • Renderiza paisagens conectando pontos por linhas
  • Projeção isométrica e perspectiva
  • Construído em C sobre a MiniLibX
02 · Motivação

Objetivo

Transformar uma matriz de alturas em um objeto 3D interativo, exibindo relevo e profundidade.

Projeções 3D Bresenham Clipping Câmera Transformações Eventos
03 · Entrada

Formato do mapa .fdf

Cada arquivo é uma matriz de inteiros — a altura (Z) de cada ponto (X, Y):

# maps/pyramide.fdf
0  0  0  0  0
0  5  5  5  0
0  5 10  5  0
0  5  5  5  0
0  0  0  0  0

Cor opcional: 10,0xFF00AA. Linhas e colunas devem ser consistentes.

04 · Recursos

Funcionalidades

  • Leitura e validação de arquivos .fdf
  • Renderização wireframe com cor por altura
  • Rotação, escala e translação interativas
  • Alternância entre projeção isométrica e perspectiva
  • Clipping para evitar artefatos fora da tela
  • Mais de 20 mapas de teste disponíveis
05 · Estrutura

Arquitetura do código

read.c

Parse e validação dos mapas .fdf

projection.c

Projeções isométrica e perspectiva

bresenham.c

Desenho eficiente de linhas pixel a pixel

transform.c

Translação, escala e rotação 3D

clipping.c

Recorte de linhas (Cohen–Sutherland)

camera.c

Estado e movimentação da câmera

handle_events.c

Entrada de teclado e mouse

render.c

Pipeline de renderização do frame

09 · Setup

Como executar

Compile e abra um mapa:

$ make
$ ./fdf maps/42.fdf

Ou rode em ambiente isolado com Docker:

$ docker compose up --build
