01 · Introdução

Visão Geral

FdF converte mapas de altura 2D em uma representação 3D wireframe interativa.

  • Renderiza paisagens conectando pontos por linhas
  • Projeção isométrica e perspectiva
  • Construído em C sobre a MiniLibX
02 · Motivação

Objetivo

Transformar uma matriz de alturas em um objeto 3D interativo, exibindo relevo e profundidade.

Projeções 3D Bresenham Clipping Câmera Transformações Eventos
03 · Entrada

Formato do mapa .fdf

Cada arquivo é uma matriz de inteiros — a altura (Z) de cada ponto (X, Y):

# maps/pyramide.fdf
0  0  0  0  0
0  5  5  5  0
0  5 10  5  0
0  5  5  5  0
0  0  0  0  0

Cor opcional por ponto: 10,0xFF00AA. Linhas e colunas devem ser consistentes.

04 · Recursos

Funcionalidades

  • Leitura e validação de arquivos .fdf

06 · Matemática

Projeções 3D

Isométrica

x' = (x − y) × cos(30°) y' = (x + y) × sin(30°) − z

Escala uniforme sem distorção de perspectiva. Ideal para leitura de mapas e comparação de alturas.

Perspectiva

f = FOV / (FOV + z) x' = x × f y' = y × f

Objetos distantes aparecem menores. Dá sensação de profundidade realista — alternável com P.

07 · Algoritmo

Algoritmo de Bresenham

Rasteriza linhas em pixels usando apenas aritmética inteira — sem ponto flutuante, sem divisões.

A variável err acumula o erro fracionário e decide se Y avança a cada passo em X:

// octante 0 — 0° ≤ slope ≤ 45°
err = 2*dy - dx;
while (x <= x1) {
  plot(x, y);
  if (err > 0) { y++; err -= 2*dx; }
  err += 2*dy;
  x++;
}

O projeto espelha eixos e direções para cobrir todos os 8 octantes.

(0,0) → (7,3)

08 · Algoritmo

Cohen–Sutherland Clipping

Divide o espaço em 9 regiões com um código de 4 bits por endpoint. Linhas totalmente fora são descartadas sem cálculo; as que cruzam a borda são recortadas.

09 · Cores

RGB por Altura

Cada aresta recebe uma cor proporcional à sua altura média — usando interpolação linear (lerp) canal a canal:

#4effac z = z_min z = z_max #7ce7ff
t = (z − z_min) / (z_max − z_min) R' = R_low + (R_high − R_low) × t G' = G_low + (G_high − G_low) × t B' = B_low + (B_high − B_low) × t cor = (R' << 16) | (G' << 8) | B'
