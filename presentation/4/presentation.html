A. General Notes

FdF — em francês, "fio de arame". O programa lê arquivos .fdf contendo uma matriz de alturas e os renderiza como modelos wireframe 3D — só as arestas, sem preenchimento.

  1. N1. Escrito em C sobre a biblioteca MiniLibX (X11).
  2. N2. Parser tolera espaços, tabs e cores opcionais em hexadecimal.
  3. N3. Projeções: isométrica, perspectiva e top-view.
  4. N4. Rasterização via algoritmo de Bresenham; clipping Cohen–Sutherland.
  5. N5. Sem aceleração GPU — desenho em CPU, frame a frame.

B. Design Intent

[✓]
Parser robusto para arquivos .fdf, validando formato e cor.
[✓]
Transformações 3D — escala, rotação (X, Y, Z), translação.
[✓]
Projeções isométrica (paralela) e perspectiva (divisão por z).
[✓]
Bresenham em 8 octantes, sem chamadas de ponto-flutuante no inner loop.
[✓]
Clipping de linhas + near-plane para evitar artefatos.
[✓]
Event loop interativo — teclado, mouse, redimensionamento.

F. Line Rasterization / Bresenham, 1965

Algoritmo de 1965 para rasterizar uma reta entre dois pontos inteiros — apenas com somas, subtrações e comparações.

// pseudo-código do octante padrão
error = delta_x - delta_y;
while (1) {
    put_pixel(x, y, color);
    if (x == x2 && y == y2) break;
    e2 = 2 * error;
    if (e2 >= -delta_y) { error -= delta_y; x += xi; }
    if (e2 <=  delta_x) { error += delta_x; y += yi; }
}

G. Isometric Projection

Três eixos a 120°. Sem perspectiva. Linhas paralelas continuam paralelas.

// src/projection.c
angle_x = ANG_30_RADIAN;                   //   30°
angle_y = ANG_30_RADIAN + ANG_120_RADIAN;  //  150°
angle_z = ANG_30_RADIAN - ANG_120_RADIAN;  //  -90°

x' = x·cos(α) + y·cos(β) + z·cos(γ);
y' = x·sin(α) + y·sin(β) + z·sin(γ);

H. Perspective Projection

Pontos distantes ficam menores: divide por z.

z1 = p1.z - depth_z;
z2 = p2.z - depth_z;

camera_clipping(line, &z1, &z2);   // near-plane
if (!line->show) return;        // 100% atrás

if (z1 != 0) {
    p1.x = (p1.x * focal_length) / z1;
    p1.y = (p1.y * focal_length) / z1;
}
⚠ NOTA Sem o clipping de near-plane, pontos com z < 0 vão pra +∞ na tela.

I. Line Clipping / Cohen–Sutherland

  1. I.1 code1 | code2 == 0 → 100% dentro · desenha
  2. I.2 code1 & code2 != 0 → 100% fora · descarta
  3. I.3 caso contrário, recorta na borda mais externa e repete

O. Revisions / Lessons

REVTAGNOTE
R1BUG
Divisão por zero na perspectiva. Ponto exatamente no plano focal explodia. Fix: clipar antes da divisão.
R2TIP
Ordem importa: R · S · T ≠ T · S · R. Aplicar rotação antes de translação produz resultado oposto.
R3PERF
Mapa 100-6 lentíssimo. Parser tinha um realloc por linha. Buffer fixo + crescimento ×2 resolveu.
R4SEG
Linhas fora do viewport. MiniLibX escrevia fora do framebuffer. Cohen–Sutherland + bounds-check.
