FdF — "fil de fer", fio de arame em francês.

Projeto da 42 São Paulo que renderiza, em puro C, paisagens 3D como modelos wireframe — só as arestas, sem preenchimento.

$ man bresenham

Algoritmo de 1965 para rasterizar uma reta entre dois pontos inteiros — apenas com somas, subtrações e comparações.

// pseudo-código do octante padrão
error = delta_x - delta_y;
while (1) {
    put_pixel(x, y, color);
    if (x == x2 && y == y2) break;
    e2 = 2 * error;
    if (e2 >= -delta_y) { error -= delta_y; x += xi; }
    if (e2 <=  delta_x) { error += delta_x; y += yi; }
}
   y                    ←  reta ideal
   ▲      ●─●            ●  pixel desenhado
   │    ●─●
   │  ●─●
   │●─●
   └────────▶ x

$ ./fdf --proj=persp

Pontos distantes ficam menores: divide por z.

z1 = p1.z - depth_z;
z2 = p2.z - depth_z;

camera_clipping(line, &z1, &z2);   // near-plane
if (!line->show) return;        // 100% atrás

if (z1 != 0) {
    p1.x = (p1.x * focal_length) / z1;
    p1.y = (p1.y * focal_length) / z1;
}

⚠ sem o clipping de near-plane, pontos com z < 0 vão pra +∞ na tela.
